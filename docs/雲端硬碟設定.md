# 會議資料存到 Google 雲端硬碟：設定步驟（DievE 用學生會公用帳號操作）

做法：秘書處在「行政會議資料」按「存到雲端」，或在會議紀錄預覽按「存到雲端」，網站會用「按的人自己的 Google 帳號」把內容存成一份 Google 文件，放進學生會的雲端資料夾。權限是 `drive.file`：只能碰這個網站建立或你選過的檔案，看不到整個雲端硬碟。沒有新增伺服器。
資料夾每台裝置第一次按時會跳出選擇視窗，選學生會的「會議記錄」資料夾一次，之後記在那台裝置。資料夾網址不寫進 repo。

## 要先做的四件事（都在 Google Cloud 主控台，專案 stustsa-council）
1. 啟用兩個服務：打開 https://console.cloud.google.com/apis/library?project=stustsa-council ，搜尋並按「啟用」：`Google Drive API`、`Google Picker API`。
2. 授權範圍：打開 https://console.cloud.google.com/auth/scopes?project=stustsa-council ，按「新增或移除範圍」，勾選 `.../auth/drive.file`（非敏感範圍，不用送審），儲存。
3. 取得用戶端 ID：打開 https://console.cloud.google.com/apis/credentials?project=stustsa-council ，在「OAuth 2.0 用戶端 ID」找類型「網頁應用程式」那一列（名稱通常是 Web client (auto created by Google Service)），點進去：
   - 「已授權的 JavaScript 來源」要有 `https://stustsa.github.io`，沒有就新增、儲存。
   - 複製最上面的「用戶端 ID」（xxxx.apps.googleusercontent.com 結尾；這不是密鑰，可以貼給我）。
4. 瀏覽器金鑰：同一頁「API 金鑰」找到網站用的那把（Browser key），點進去，若有「API 限制」，把 `Google Picker API` 加進允許清單；網站限制要有 `https://stustsa.github.io/*`。

## 做完之後
把第 3 步的「用戶端 ID」貼給我，我會填進 `core/js/drive.js` 開一個小 PR；合併後秘書處就會看到「存到雲端」。在那之前按鈕是藏起來的。
第一次按時：Google 會問要不要讓學生會網站存取（只有「查看及管理這個應用程式建立的檔案」），按允許，再選資料夾。

## 注意
- 存進去的是 Google 文件（可編輯、可從 Google 下載成 PDF），不是 PDF 檔。
- 要寫入的人必須對該資料夾有「編輯者」權限（資料夾共用設定）。
- 換資料夾：清掉這個網站的網站資料，或之後再加「換資料夾」鍵。
