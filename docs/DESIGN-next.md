# 學生會會務系統：設計規格（DESIGN.md）

這份規格描述的是完整模擬頁上的介面：https://claude.ai/artifact/DKPac8pGJYoGMGDapnK2Hv

## 一、整體原則

- 保留黑白極簡、圓角膠囊、細線、狀態燈號的語言；不做成企業後台。
- 直接操作優先：文字點了就改、卡片直接拖、時間直接調。
- 桌面與手機用不同版面，不把桌面縮小給手機。部門內一次只顯示一區。
- 相同操作全站同一套動畫與回饋；跟互動、變化有關的細節都要有動畫。
- 介面不放註解或教學文字，靠介面本身讓人看懂。只留標題、目前的值、狀態、按鈕、錯誤訊息、確認句。
- 不要原生下拉、原生勾選外觀；用自製元件。自製下拉展開時清單蓋在後面的欄位、標籤、按鈕上面，每個選項都點得到。
- 編輯中的輸入欄位以外，文字與物件都不能被選取。
- 每個互動都要有退路（見第十三節）。
- **分享預覽**（貼連結到 LINE、IG、FB 時顯示）：主頁與各部門看板用同一組，不帶部門的標題或圖——標題「學生會數位系統」、圖 `https://stustsa.github.io/council/dept/cover.png`（1200×630）、說明「南臺科技大學學生會各部門的議題進度、即時回報與每週概述。」；只有 og:url 各寫自己的網址。看板的靜態網頁標題也是「學生會數位系統」（爬蟲不跑 JS，各部門的連結都拿到這個）。設定裡沒有改分享預覽的入口，要改就直接改 `index.html` 與 `home.html`（兩頁一起改；DievE 11/19 定）。

## 二、主題與色彩

### 變數（每一組主題都要定義這一整組，淺色與深色各一份）

| 變數 | 用途 |
|---|---|
| `--bg` | 頁面底 |
| `--blk` | 色塊、卡片、膠囊的底 |
| `--blk2` | 次色塊（分段切換的軌道、不可用的斜紋） |
| `--ink` | 文字、實心圖形 |
| `--muted` | 次要文字 |
| `--hair` | 細線 |
| `--acc`／`--acc-ink` | **選中**：選到的日期、選到的議題條、符合條件的時段 |
| `--acc2`／`--acc2-ink` | **焦點**：主頁焦點框、今天、要注意的數字 |
| `--pri`／`--pri-ink` | **主要動作**的底與字：分段切換與工具列的鏡片、實心膠囊鈕、新增圓鈕、併入鈕、部門新增鈕、全會行事曆鈕、今日卡片。預設＝`--ink`／`--blk` |
| `--ok`／`--late` | 完成綠；逾期與刪除紅。紅色只給逾期、刪除、「報告」 |
| `--blk-sh` | 色塊與膠囊的陰影，預設 none（只有「柔光」主題有值） |

### 主題由使用者自己選

- 設定 → 帳號 → 外觀：淺色／深色的分段切換；下面一格一格的主題按鈕（三顆圓＝色塊、主要動作、選中，加名稱；選到的加粗框）；最下面一列「音效」開關。
- 十三組主題：米黃（預設）、白藍、黑白黃、灰綠、霧藍、爐火、粉彩、柔光、暖陽、櫻花、森林、海洋、紫藤（2026-11-21 加後四組）。色碼見本節最後的表。
- 部門標誌的藍（#0a5baa）與黃（#f0bc23）不跟著主題變。深色模式時，標誌裡的藍改成白（#fff），黃不變；原本就是白色的零件跟著所在底板的底色，才分得出來（DievE 11/16 定，11/19 確認）。專案色塊各有自己的顏色。
- 新主題只能改上面那組變數的值，不能針對某個主題另外寫元件樣式。
- 換主題、換深淺色：整個畫面一起淡過去（140ms、等速），文字、色塊、工具列同一個時間到位；那一下各元件自己的顏色過渡全部停掉，只有分段鈕的滑塊照常滑。淡的途中再點別的地方，淡出立刻結束、那一下照樣算數。不支援整頁淡出的瀏覽器或關掉動態時，整頁同時直接換。

## 三、材質、圓角、層次

- **材質只有平面**。沒有漸層、沒有細線圖形、沒有毛玻璃、沒有光暈。色塊三種：平面、斜紋（不可用、缺席）、外框（次要動作）。
- **圓角**：大色塊與卡片 18；內層項目 14；小方塊 12；膠囊與圓鈕全圓。
- **相鄰的元件一定留縫**，不做「相連又各自圓角」。
- **陰影只給浮在內容上面的東西**：手機卡片堆、手機的主頁下排（桌面下排是分開的圓鈕、不帶陰影，ui-12）、部門工具列（外加一圈 1px 細線）、新增圓鈕。平鋪的色塊不用陰影（「柔光」主題例外，整組主題的色塊帶雙向柔影）。柔光的柔影要完整畫出來、不被捲動容器或上面的疊層切成直線：捲動容器留出陰影的外擴距離（`--sh-pad`，只有柔光有值）再用負邊距抵掉，色塊位置不變；設定開著時部門標題列疊在設定層上面（ui-10 C）。
- 區分「實心／外框」來表達兩種狀態或兩個對象，不多用一個顏色（點名的出席／請假、找共同時間的兩個單位、時間線的完成／未完成）。

## 四、字

- 頁面標題與區塊標題 700 並加字距；項目名稱 500；內文 400。中間不留 400–500 的大字。
- 大數字用 Jost 300。數字一律用等寬數字的字型類別（`.num`）。
- 標題上方放很小、字距很疏的英文小標（Jost 10–10.5px、字距 .22em）。部門英文名：PRESIDENT、SECRETARIAT、STUDENT RIGHTS、MARKETING、FINANCE、EVENTS、CLUB AFFAIRS、PUBLIC RELATIONS、FACILITIES。

## 五、動態

### 時間與曲線
- `MO`：fast 160｜base 280｜slow 460｜layout 560（毫秒）。
- 曲線：強回彈 `cubic-bezier(.3,1.45,.45,1)`（只給小東西：圖示、鏡片、勾選、圓鈕）；柔回彈 `cubic-bezier(.25,1.12,.4,1)`（版面的位移、長高、依序浮現）；出 `cubic-bezier(.2,.9,.25,1)`；入 `cubic-bezier(.4,0,1,1)`。
- **只有主頁要遊戲感**；其餘畫面 Q 彈、連續，不要快、不要斷，不靠「打斷感」。

### 三條版面規則
1. 長度：區塊變高時用裁切把新長出來的部分露出來，變矮時高度滑過去。手機不做高度與裁切動畫。
2. 位置／進出：同一頁重畫時，位置變了的滑到新位置，新的由下浮現，不見的留分身淡出縮小。
3. 換內容：舊的原地淡出、新的一列一列浮上來。

### 畫面更新（影響順暢度，必守）
- 同一個畫面重畫時**原位更新**，只改有變的節點，不整頁重建：打字時焦點與鍵盤不掉、捲動位置不跳、沒變的東西不重跑動畫。
- 換畫面時，標題列與主頁下排是**同一個節點、留在畫面上不拔下來**，只改有變的地方；沿用時不參加進場動畫。
- 進場動畫只能挑版面上的區塊，不能挑到圖示或標誌的內部零件；class 名稱不要跟圖形共用。
- 編輯中按卡片上的按鈕不能讓輸入欄失焦。

### 整頁過場
- 開頁、換區：每一塊由下浮上來帶柔回彈（單塊 560ms、每塊錯開 30ms，最多 16 塊）。淡入的終點是元件自己的透明度：本來就半透明的（完成紀錄的膠囊、已離席的列、沒選到的色塊）直接淡到半透明，不會先變成不透明再跳回去。
- 部門內換分頁：舊內容往一邊退、新內容從另一邊進，方向跟工具列一致（桌面上下、手機左右）。
- 桌面主頁進部門：被點的色塊連同標誌鋪滿畫面；回主頁時收回原本那一張。
- **手機主頁進部門**：其他卡片先縮一下再各自帶偏移與旋轉往上下彈開（460ms），主頁其餘東西淡出 → 被點的卡片整張翻面、邊翻邊鋪滿（前半 230ms 卡片轉到側面，後半 430ms 畫面大小的底板帶部門標誌從側面轉正；延遲 200ms 起跑）→ 部門畫面的物件不規則浮現（每塊延遲 0–320ms、方向距離大小各自不同），標誌同時淡出。只動 transform 與 opacity。
- 進部門等看板穩定的那一段（過場終點的底板還蓋著、最多 1.6 秒）：部門標誌輕輕呼吸（放大 4% 再回來，1.3 秒一輪，延遲 0.3 秒才開始、載入很快時看不到）。只動 transform、由合成器執行，主執行緒忙時也不頓；看板穩定就照原本的淡出收掉，不為了動畫延長等待。
- 登入到主頁：開場的兩個小人縮到左上角的標誌上。
- 容器轉化：即時回報與完成紀錄的卡片，是那顆膠囊自己長成卡片（外框從膠囊位置展開、標題滑到卡片標題、其餘淡入），收回時反過來。

### 彈簧與回彈
- **工具列的鏡片有彈簧物理**：按下時鏡片放大、那一格的內容放大到 1.2 倍、整條列沿長邊多放大 16px；移動時鏡片依速度沿移動方向拉伸（最多兩成）、垂直方向略縮；點別的分頁＝按下 → 滑過去 → 放開；只有按在鏡片那一格才能拖，拖動時鏡片跟著手指，放開吸到最近的一格；拖過兩端時整條列跟著偏移最多 4px。設定鈕按下放大 4px，被指標拖著時微微偏移與拉伸，放開彈回。分段切換的鏡片也可以拖，超出邊界有阻力，放開彈到最近的一格。
- **拉過頭的回彈**：每個可捲動的地方（整頁、卡片內容、主頁色塊列、下排）捲到底還繼續拉時，內容被拉開一點並沿拉動方向微微拉伸，拉得越遠阻力越大；放開用彈簧彈回。滾輪與手指都有。iPhone 用系統自己的回彈。
- 今日卡片放大：底板從卡片的位置與圓角揭開（彈簧 阻尼比 .62／勁度 190），收回用 .55／90，卡片接著播縮過頭再彈回的那一段。

### 圖示動作
- **工具列與標題列的圖示由幾個零件組成，各自會動**。按下去從頭播一次（按下的當下就開始）；滑鼠停在上面時循環，移開後播完這一圈才停。重畫畫面時不能打斷正在播的動作。
  - 即時回報：中間圓點縮到 55% 再回來，兩圈波紋一前一後閃一下（1.4 秒）。
  - 進度：三條橫線從左端依序縮到 35% 再伸回來，每條錯開 0.12 秒（1.3 秒）。
  - 完成紀錄：圓圈裡的勾重新畫一次（1.4 秒）。
  - 設定：兩顆滑鈕一顆往左、一顆往右各滑 6px 再回來（1.4 秒）。
  - 首頁：整顆房子往上跳 1.8px 再落回（1 秒）。
  - 通知：鈴鐺以頂端為軸左右搖四下，幅度遞減（14°、−11°、7°、−4°；1.2 秒）。
- 首頁鍵是簡單的五邊形房子（沒有門），按下整顆往上跳一下。
- 卡片內其他圖示：按到時各自的小動作（加號轉、勾勾彈出、箭頭往前…），同一套時間與強回彈。
- 部門標誌：九個部門各有 SVG；在主頁被選到時小人做一次動作。零件只往離開鄰居的方向動。

### 開場
- 兩個小人從兩側滑入 → 扣上 → 標誌上移 → 標誌移開之後，STUSTSA 與「南臺科大學生會」才由左到右逐字揭開（字一出現就不跟小人重疊）→ 完成後才出現登入鈕。文字寬約為小人的 2.1 倍；標誌大小同時看畫面寬與高（高最多四成）。深色時左邊小人只留線稿。

## 六、版面骨架

### 主頁（盡量單純）
- 只有：左上橫式學生會標誌（只有標誌本身，不加底）、時間、設定、部門／專案切換、色塊、下排。工具列、通知、逾期數字都要進部門才看得到。
- **桌面**：一排橫向色塊，焦點那塊放大，整列共用一個焦點框滑到新的那張；滾輪、方向鍵、點擊切換。色塊內容：英文小標、名稱、標誌、進行中的卡片數。
  - **垂直比例像 Switch 主畫面**（ui-12，使用者 11/20）：上排（標誌、時間、設定）、色塊列、下排三段，用視窗高度分配留白：色塊列略高於畫面中線（中心約在畫面高度 45%），下排在色塊與畫面底緣之間（色塊底到下排、下排到畫面底的留白差不多），下半不留大片空白。色塊邊長跟著視窗高度（約畫面高的 30%，160～340px；窄而高的視窗改看寬度），焦點那塊放大 1.13；色塊之間的間距跟著邊長（0.16 倍）。
- **手機**：錢包式卡片堆。**間距只有一條規律**：焦點卡整張露出（高 196），其餘每張只露同樣高的一條（60）；退到後面的疊在上方（每退一張縮 5%，最多露兩張，第三張邊退邊淡掉），還沒輪到的疊在下方，焦點卡與下一張之間留 10；整疊貼齊上緣。
  - 滑動：跟著手指（每 140px 一張）；放開後帶著手指速度用彈簧滑到定位（勁度 230、阻尼比 .74），甩得快多走幾張（最多 3 張）；拉過頭阻力 .35。點露出的那一條＝叫到焦點，點焦點卡＝進入。
- **下排**：寬度跟著內容、以整個畫面寬置中（不是以內容區）。桌面是一顆一顆分開的圓鈕（沒有共用的底、不帶陰影），直徑約色塊邊長的 0.28、間距約直徑的 0.42，圓鈕裡的圖示與首字母跟著直徑等比例；手機是浮在上面（帶陰影）的膠囊，圓鈕 44px（ui-12）。一顆「全會行事曆」圓鈕，後面是個人常用連結（只放該網站的圖示：先向那個網站自己要 `/favicon.ico`；要不到再向 Google 的圖示服務 `https://www.google.com/s2/favicons?domain=<網域>&sz=64` 要，只送網域（`hostname`，經過 `encodeURIComponent`），不送完整網址與路徑；Google 拿不到時回的預設地球圖（要 64 卻回 16×16）當成沒有，任何一步回寬或高 ≤ 2 的極小圖（1×1 透明佔位）也當成沒有；內網／本機網域（IP、`localhost`、沒有點的單段名、`.local`、`.internal`、`.lan`、`.home.arpa`、`.localhost`）兩步都不要，直接首字母；兩邊都沒有才顯示網域第一個字母（只有這個字母會是 punycode 的 x 時——去掉 `www.` 後的網域開頭是 `xn--`，例如中文網域、中文子網域——改用連結名稱的第一個字，照字素切，emoji、組合字完整一個、不轉大寫，開頭的零寬空格等格式字元跳過；中文只在後段的網域（`example.台灣`、`blog.例子.tw`）照樣用網域首字母；沒取名稱（名稱空的、只有格式字元、或名稱就是這個網域，含寫成 `www.` 或完整網址）時仍是網域第一個字母；DievE 11/19 定），做成跟下排其他圓鈕同大小的圓鈕、字置中、顏色只用主題變數。圖片一律不帶 referrer；各網站的結果只記在記憶體，不另外存。網域會送到網站本身與 Google 的圖示服務；瀏覽器允許第三方 cookie 時，送到 Google 的請求會帶 Google 的 cookie（DievE 11/19 定）），最後「+」進入編輯。每個連結都是跟下排其他圓鈕同大小的圓鈕（手機 44px；桌面跟著色塊，見上），有網站圖示時也一樣：圓的底色跟首字母圓鈕同一個主題變數，圖示（44px 圓鈕時 26px、跟著直徑等比例，不裁成圓、不變形）放在圓的正中間（DievE 11/19 定）。**下排各元素（全會行事曆、各連結、「+」、編輯中的返回鍵）的中心在同一條水平線上**。滑過、按下連結跟下排其他圓鈕同一套回饋（微微放大、按下縮回，只動 transform；關掉動態時不動）；滑過移開、進部門再回主頁、新增與移除連結、圖示載入前後，連結都回到原位（DievE 11/19；「放大」要不要改成「上揚」待決定）。新增時填網址與名稱：網址只收 http(s)（沒寫協定＝https，其他協定一律不收），名稱可空（空的用網域）、最長 30 字；最多 12 個，滿了「+」不出現。編輯中：連結右上角紅色 × 移除；輸入框左邊返回鍵＝結束編輯；Enter＝加入；Esc、點下排以外＝結束。桌面滑鼠停在連結圖示上：圖示上方浮出名稱的小膠囊（自製，跟著主題色，淡入 fast；不用 title）；手機不浮出。寬度改變時滑到新的寬度（只動 transform／opacity）。連結只存在這台裝置，不動後端，只有自己看得到（DievE 11/18 定）。
- 從主頁進會長室、秘書處，直接落在各自的畫面；自己的分頁排在工具列第一格。

### 部門內

## 七、即時回報

### 清單
- 一筆一顆膠囊（高 54）：狀態燈號、名稱、右邊紅字「報告」。標了報告的排在上面，用一條細線隔開。
- 長按拖曳：拖到另一顆上放開＝換位置；拖到左上角＝刪除（先確認）、右上角＝完成。越靠近哪一角就往那角歪、染上那角的顏色。
- 完成：膠囊被吸進右上角，角落鼓一下，其餘滑上來補位；右上漫開光暈、彩帶、一段上行的音，約兩秒，不擋操作。

### 卡片
- 第一排：（全螢幕時）返回鍵、狀態燈號、名稱、編輯次數的小膠囊（只寫數字，點了看編輯紀錄）。
- 第二排：上一張／下一張（實心三角的外框膠囊）、紅色「報告」。
- 第三排：狀態標籤、負責人、最後更新時間。
- 內容：逐行，種類有文字、核取、時間；另外有超連結膠囊。
- 底部工具列常駐：左邊母議題膠囊（點開選單），右邊文字、人、時間、地點、核取、超連結。
- **時間行＝時間線**：每個時間行左邊一顆圓點（11px），相鄰的時間行用一條 1.5px 細線串起來；**圓點就是核取，空心＝還沒、實心＝完成**（點圓點切換）。時間是純文字（逾期紅字），後面接名稱，地點靠右、次要色；不用色塊。文字太長折行時不會跑到圓點下面。編輯中時間變成可點的淡底膠囊，點了進時間頁。
- 核取行：方形勾選框，勾了文字變淡加刪除線。
- 人、時間、地點：卡片內容換成那一頁，那顆圖示放大、其他變淡。人＝「負責人｜相關人」兩欄。時間頁：日期、時刻（預設現在、分鐘取 5）、結束時刻、可加結束日期；桌面先點選一段再用滾輪、方向鍵或數字調整。

### 編輯規則
- 點名稱、一行、核取框、「沒有說明」就在原位進入編輯。沒有儲存、取消、編輯鈕。
- 編輯中點外面＝存檔並離開編輯（出現「已儲存」與「復原」）；再點一次外面＝卡片收回。
- **手機與中等寬度（卡片寬不到 980）**：卡片從膠囊長成全螢幕，左上返回鍵存檔並縮回膠囊；內容自己捲動，底部工具列固定。
- **寬螢幕**：左邊膠囊清單、右邊卡片；進入編輯時鎖住整頁捲動。
- 上一張／下一張：卡片外框留在原地、高度滑到新的；舊內容往一邊滑出、新內容從另一邊滑進，底部工具列不動。

### 待併入（會議帶回來的事）
- 放在即時回報最上面。每一筆：左邊大日期（沒有日期的決議顯示旗子）、細直線、右邊內容與來源（哪一次會議、哪一張卡），最右一顆圓形確認鈕＝併入。
- 內容下面「編輯」（原位改那一句；Enter 或點別處存、Esc 不改）與「移除」（先確認）。兩筆以上才有「全部併入」。
- 併入＝那一行變成這張卡自己的核取待辦，編輯紀錄記一筆來源。

### 完成紀錄
- 外觀跟即時回報的卡片一樣完整（狀態「完成」、負責人、完成日、逐行內容唯讀、編輯次數可看紀錄）。
- 打開的卡片右下「移回即時回報」（誤拖完成的退路）。

## 八、進度

- 時程條比照 Android Material 的音量滑桿：已過的一段、直立把手、還沒到的一段，三者之間留縫；圓角矩形。名稱與百分比不能被把手蓋住，放不下時移到上方或右側；負責人放不下收成「+N」（手機改放下方議題區塊）。把手位置＝時程百分比。
- 甘特圖每一列也是同一種滑桿式時程條（2026-11-20 使用者定，ui-12）：條只畫在議題期間，把手＝今天在期間的位置（跟今天線對齊；還沒開始在最左、已經結束在最右）；選中的議題條用選中色，其他列的已過段＝`--ink` 48% 混 `--blk`、還沒到的一段（每一列）＝`--ink` 15% 混 `--blk`（ui-13：原本用 `--blk2`，跟卡片底色太近、兩段分不出來；亮度比至少 1.8）；條上不放名稱與百分比（名稱在左欄）。註記：最新一筆深色膠囊，其他是條上方的短線。
- 狀態標籤可自訂，不限四種；文字視覺置中。甘特圖註記不用小圓點。
- 時間行寫進母議題的處理紀錄（勾了「也寫進母議題的處理紀錄」）：卡片裡那一行還沒勾之前，處理紀錄與甘特圖註記半透明（50%，同完成紀錄）；勾了變回不透明（ui-11，見 DESIGN.md「處理紀錄的半透明」）。
- 「+ 議題」新增後直接在名稱上打字；議題名稱點了就改；全部／上學期／下學期可切換。選中的議題條用選中色，把手用深色。
- 專案看板最上面有抬頭：日期、總召、倒數（D−N／D+N）。

## 九、行事曆與通知

- **部門內的通知鈕**進到這一頁，由上到下：今日／明日 → 逾期 → 行事曆。
- **今日／明日**：兩張並排卡片（今日＝主要動作色底）。點今日＝放大成全螢幕「今日」層（大日期、今日、月份與星期、關閉鈕、「本來就要做」清單），Esc 可關；點明日＝行事曆選到那一天。
- **逾期**：卡片堆只列逾期的時間。左滑＝延後，右滑＝改成具體時間。
- **海報月曆**：超大月份數字加英文縮寫、右上兩行年份；週一開頭，上面一排 MON–SUN；日期只有數字、沒有格線；月曆上不寫字，單天的事＝日期下一顆小點、跨天＝橫跨那幾天的細線（兩端圓點），同一週撞在一起的往下排一層（每層 9px）；選到的日期＝選中色實心圓（直徑 40），今天＝焦點色粗體；底下一行「部門・學生會」。點日期，下面的清單換成那一天；右上的月份鈕點開選月份。
- **五類模式**：本部門、會長室、活動、會議、其他（自由勾選部門）。
- **主頁的全會行事曆**是公共版：只看全會的活動與會議（全部／活動／會議），沒有今日／明日與逾期。
- **找共同時間**：行事曆抬頭一顆鈕，按下後選兩個單位、切「都有空／都沒空」。月曆照樣在但不畫事件，每個日期底下一條短條（24×4）＝那天 08–22 時符合條件的比例；點日期，下面出現那一天：符合的總時數、一條時間軸（上半實心＝第一個單位有事、下半外框＝第二個單位有事，符合的時段＝上緣一條選中色加很淡的底）、確切起訖時段的膠囊。
- **會長預約**：「會長室」模式點可預約時段 → 填事由 → 待確認；會長室核准或拒絕。自己送出、還在待確認的預約點了可以取消（先確認）。

## 十、秘書處

- **會議畫面**兩塊：抬頭（會議次數、名稱與狀態、主要動作）；下面三個分頁「議程｜點名｜上次決議」。
- **議程**：左欄部門、右欄事項。每一列就是那個部門的即時回報卡片，點了在原位打開同一套卡片編輯器（手機全螢幕）。每個部門那一列右邊一顆圓形「+」＝在那個部門新增事項。
- **秘書處改別部門的卡片要明確送出**：
  - 編輯中卡片標題下面一排「上一步」「送出」。改的內容先留在這張卡上，按送出才寫進該部門的卡片；送出後顯示「已送出」與部門名。
  - 包含直接勾核取框、切「報告」，都要送出才生效。
  - 「上一步」一次退回一個看得出差別的步驟。
  - 有沒送出的修改時：點外面、換張、新增都不動（送出鈕晃一下）；手機返回鍵先問「放棄未送出的修改？」。
  - 卡片右上：上一個／下一個（照議程順序、跨部門）與「+」。
  - 工具列多一顆「決議」：加一行帶「決議」標籤的備註。議程列上顯示這張卡有幾條決議。
  - 議程列可以長按拖到右上＝幫忙按完成。
- **定版**後可以「取消定版」；「輸出會議紀錄」會結案且不能回頭，先確認；確認後帶到「會議資料與紀錄」頁，並把每條決議送到該部門的待併入。
- **會長室的開關**（權限分頁「秘書處會議紀錄」）關閉、或會議已結案時，秘書處看別部門的卡片是唯讀。
- **點名**：上面三個大數字（出席、請假、缺席）；下面一個部門一列，列上一排小方塊＝每個人的狀態（實心出席、外框請假、紅色缺席）與到場數；點開逐一點名，點一下輪流三種狀態。整列寬的按鈕被指到時不放大，改成底色加深。
- **匯入名單**：點名分頁右上。文字框（預填目前名單）加「選擇檔案」；一行一人「部門、職稱、姓名」，分隔符號與順序不拘；匯入後照部長、副部長、其他排好，回報人數、部門數、略過幾行。
- **會議資料與紀錄**（設定頁，工作報告下面，只有秘書處）：
  - 會議資料＝照報告順序列出各單位標了「報告」的事項名稱。
  - 會議紀錄＝同一份清單，會議上改過或加上的內容用紅字列在該項底下（決議標「決議」、改名列原名、會議上完成標「完成」）；會議上臨時新增的事項整項紅字。
  - 會議紀錄可設定一個雲端資料夾網址（可更改、移除）；設定後多一顆「輸出並上傳」，下面列每次上傳的時間與檔名。

## 十一、會長室

- 從主頁進去先到即時回報；「權限」是工具列最後一格。
- 權限分頁：預約（核准／拒絕）、申請（核准／拒絕）、人員（角色膠囊點開可改角色或撤銷）、QR 邀請、「秘書處會議紀錄」開關（自製 44×26）。
- QR 不常駐：平常只有要邀請的單位與角色和「產生 QR」，按了才出現 QR 與倒數，撤銷或關閉後收回。

## 十二、設定

- 進出都用工具列的設定鍵；頂端沒有 logo 與「關閉」。列下面不放說明小字。
- 子頁：工作報告（白紙預覽）、（秘書處）會議資料與紀錄、帳號（角色、外觀、登出）、標籤（人事時地物，可增刪）、編輯紀錄、備份（下載、還原）。
- 子頁或面板裡打開的表單（產生 QR、授予權限等）屬於打開它的那一頁：離開那一頁（返回、系統返回、換到別的面板、收起設定、首頁鍵）就當成取消收掉，不送出，不會留在別的頁面。

## 十三、互動完整度（每個互動都要有退路）

- 輸入類的暫時狀態：Enter＝確定，Esc＝離開，點外面＝離開（或存檔，依該元件的規則）。Esc 一律＝離開目前這個暫時狀態（搜尋、連結編輯、待併入編輯、預約填寫、月份選單、匯入名單、打開的完成卡片、今日層）。
- 會刪掉東西、或不能回頭的動作先確認：刪除卡片、移除待併入、撤銷角色、還原備份、輸出會議紀錄並結案、取消預約、放棄未送出的修改。
- 誤觸要救得回來：完成 →「移回即時回報」；定版 →「取消定版」；部門自己編輯 →「復原」；秘書處編輯 →「上一步」。

## 十四、唯讀檢視

- 沒有編輯權限的單位：部門名旁邊外框「唯讀」標籤；卡片可以展開、看編輯紀錄、上下切換，但不能改、不能勾、沒有底部工具列、沒有「報告」鈕（有標報告的只顯示紅字）、不能拖、沒有新增；通知鈕與設定鍵不出現。不能動的東西不接受點按，也不會被指到放大。
- 可編輯的單位右上有眼睛鈕，按了看別人看到的樣子。

## 十五、回饋與音效

- 可互動的東西被指到放大、按下縮回；不可互動的不放大；整列寬的按鈕不放大。
- 核取、時間調整、新出現的膠囊都有回饋動畫。
- 音效（現場合成，不載音檔）：移動焦點、進入、返回、換頁、展開、勾選、確認、否定、滾動、一般按鈕、慶祝。開關在設定 → 帳號 → 外觀，預設開。
